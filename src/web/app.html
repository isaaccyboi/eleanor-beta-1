Chai-Kan 7.74

An agentic coding harness. It reads your project, searches it, edits files, runs commands — then holds its own work to your project's tests before calling it done.

  • Read mode inspects and explains. It cannot change anything.
  • Build mode edits files and runs commands without asking first — work on a branch.
  • With verify on, failing checks are fed back and repaired automatically.
